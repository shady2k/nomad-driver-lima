# Preserved work in progress — NOT validated main

These are separate source projections of incomparable local work. They are not
merged, installed, or collectively tested. The preliminary caller 0.1.50 branch
is `snapshots/stable-create-retry/`; caller 0.1.49 remains the reviewed source
candidate on main, and 0.1.48 is the maintainer-reported installed core.

Each snapshot retains its implementation independently. Historical README/test
statements describe their original contexts and are not new acceptance claims.
Private deployment/configuration files, receipts, tokens, logs and build artifacts
are omitted. Where needed, sample identities/catalog provenance are neutralized.
The originals and complete private histories remain unchanged locally. These
projections are not complete installation bundles. Do not interpret this branch
as a release or as completed production functionality.

Root Apache-2.0 and third-party license boundaries remain applicable. Dependency
modules are retained in each snapshot; the existing binary release is unchanged.
